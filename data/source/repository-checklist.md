# Publish your LCA repository

1. Ask Codex to inspect your actual project and write a README.md covering every section in [the README requirements](readme-requirements.md). Review the document yourself and resolve or explicitly mark missing information.
2. Include calculation code, pinned dependencies/reproduction commands, permitted input data or retrieval instructions, complete dataset/mapping records, assumptions, curated consequential prompts and original/revised results. Link these files from the README.
3. Set your own GitHub repository to Public. Commit and push the independent result before class comparison. Get the full SHA using `git rev-parse HEAD` and submit it on the course website with your name, email and the course submission code. Keep a tag such as independent-run for the first version. Submit another commit after a revision; both records remain available.

Publish only data you may redistribute. Keep full names and email addresses in the private submission form. Never commit passwords, API keys, course codes, .env, session files, private messages or restricted database dumps, including in Git history. Document IDs, versions and retrieval instructions for restricted inputs.
