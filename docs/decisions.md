## 실행 순서와 보존 상태

1. 과제 사이트의 README·저장소 체크리스트, BOM, 매핑 표, 실행 명세를 전부 읽고 `data/source/`에 보관했다.
2. 공식 USLCI 1.2026-09.0 `.zolca`를 GitHub에서 다운로드했다. 같은 릴리스의 Commons JSON-LD 내보내기를 공개 예시 키로 받아 로컬 계산에 사용했다. 이후 공개 예시 키는 사용량 제한을 반환했으며, 추가 API 호출은 중단했다.
3. FLCAC LCIAformatter의 IPCC 계수 CSV를 GitHub에서 내려받아 사용했다. 원본 자료는 모두 `data/raw/`에만 두고 Git에서 제외했다.
4. 매핑·공급자 연결·흐름 특성화·전경 가정을 구현해 계산했다. 초기 일괄 폐기물 분류를 별도 표토·광미 및 재활용 원료 분류로 수정한 뒤 독립 실행 결과를 생성했다.
5. `results/`는 **독립 실행 결과**다. 수업 비교 이후 수정 실행은 아직 수행하지 않았다. 제출용 커밋에 `independent-run` 태그를 붙여 보존한다.

## 독립 확인 가능 항목

- BOM 완성 질량: 본체 723.0 g, 포장 137.8 g, 합계 860.8 g.
- `results/run.json`의 총량은 `results/contributions.csv`의 모든 행 합계와 일치한다.
- `results/unresolved-providers.csv`는 가정으로 대체한 공급자 교환과 그 총량 기여를 기록한다.
- `data/manifest.json`의 SHA256으로 원본 파일을 확인할 수 있다.

## 미확인 사항

- 제품 실제 제조지, 재료 등급, 부품별 수율, 공장 실측 전력, 공급업체 경로, 실제 스크랩 처리, 생산 기준연도는 확인되지 않았다.
- USLCI 외부 전력 공급자와 일부 재료 공급자는 연결되지 않았고 추정값으로 대체했다.
- 15개 다산출 공정의 원 배분 결과 재현 여부는 확인되지 않았다.
- 최종 사람 검토 및 수업 제출은 아직 완료되지 않았다.
